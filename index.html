1. 기록하는 정보와 이용 목적

다주관은 키, 현재·목표체중, 날짜별 체중, 약제명·용량·주사 시각·부위·메모와 알림 설정을 기기에 저장합니다. 이 정보는 기록 조회, 체중·BMI 표시, 주사 기록과 추정 잔여량 표시, 알림 예약 및 백업·복원에 사용됩니다. 회원가입 기능은 없으며 기록 기능을 이용할 때 이름·이메일을 입력받지 않습니다. 개인정보 관련 이메일을 보내는 경우에는 아래 연락 창구 항목의 설명이 적용됩니다.

2. 저장 위치와 외부 전송

현재 앱은 건강 기록을 기기 내부 데이터베이스에 저장하며, 개발자가 운영하는 서버에 업로드하거나 광고 요청에 건강 기록을 첨부하지 않습니다. 다만 광고 SDK의 통신과 사용자가 직접 선택한 백업 파일 공유는 별도로 이루어집니다. 기기 운영체제의 백업·복원 설정에 따라 앱 데이터가 기기 계정의 백업에 포함될 수 있습니다.

3. 광고와 Google의 정보 처리

현재 버전은 Google AdMob 테스트 배너를 요청하며 비개인화 광고 옵션을 사용합니다. 테스트 광고나 비개인화 설정도 정보 처리가 전혀 없다는 뜻은 아닙니다. Google Mobile Ads SDK는 광고 제공·측정, 진단, 부정 사용 방지를 위해 IP 주소, 기기·광고 식별자, 광고와의 상호작용 및 진단 정보 등을 처리할 수 있습니다. IP 주소로 대략적인 위치가 추정될 수 있습니다. 처리 항목·보관·국외 처리에 관한 세부 사항은 Google 정책과 SDK 설정에 따릅니다. Google의 개인정보 선택 관리 기능을 통해 앱 실행 시 광고 요청 가능 여부를 확인하고, 필요한 경우 Google이 제공하는 선택 화면을 표시합니다. 해당 화면이 제공되는 경우 설정의 광고 개인정보 설정에서 선택을 다시 확인하거나 변경할 수 있습니다. 별도 화면이 필요하지 않다고 안내되더라도 모든 개인정보 처리에 대한 동의를 의미하지 않습니다. 실제 광고 전환 전에는 해당 설정과 동의 절차에 맞게 이 방침을 갱신합니다.

4. 알림과 파일 권한

알림은 사용자가 허용한 경우 기기에 예약됩니다. 기기 설정에서 권한을 끌 수 있습니다. 백업 복원 시 시스템 파일 선택창에서 직접 선택한 파일을 읽고, 내보내기 시 사용자가 선택한 앱이나 저장공간으로 백업을 공유합니다. 이 기능을 위해 연락처·카메라·정확한 위치 권한을 요청하지 않습니다.

5. 보관, 수정과 삭제

기록은 사용자가 수정·삭제하거나 앱 데이터가 제거될 때까지 기기에 남습니다. 체중·주사 기록은 각 기록 화면에서 수정·삭제할 수 있습니다. Android의 앱 저장공간 데이터 삭제 또는 앱 삭제로 기기 내 앱 데이터를 제거할 수 있습니다. iOS의 앱 정리하기는 데이터를 보관할 수 있으므로 앱 삭제와 구분해주세요. 별도로 저장·공유한 백업 파일과 운영체제의 백업 사본은 해당 저장공간에서 직접 관리·삭제해야 합니다. Google이 처리한 정보는 Google의 보관·삭제 정책이 적용됩니다.

6. 백업과 정보 보호

백업 파일에는 건강 정보가 포함되며 별도의 파일 암호화 없이 JSON 형식으로 내보냅니다. 신뢰하는 저장공간에 보관하고 공유 대상을 확인해주세요. 앱의 작업 과정에서 내보내기·복원용 임시 파일이 캐시에 남을 수 있으며 운영체제의 캐시 정리 또는 앱 데이터 제거 시 삭제될 수 있습니다. 기기 잠금과 운영체제 보안 설정을 사용해주세요.
